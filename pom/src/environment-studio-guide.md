# Environment Studio guide

Use Environment Studio to arrange scenery and compare saved environments. Changes save automatically to your current browser’s working draft.

## Find your controls

Open or close each section independently. Saved configurations manages your alternatives. Scene & camera controls the environment, layers, floor guide and backdrop distance. Selected element contains position, size, tilt, material and support controls. Shadows controls scenery strength and ground softness.

## Arrange scenery

Click a tree, plant, cloud or fog element in the scene to select it. Drag to move it along its plane. Transparent areas do not select the element. Use the Selected element menu when something is difficult to click.

Open Add an element, choose a type and press Add element to create an independent copy. Delete selected removes that copy from the working draft. Up to 48 elements are supported.

Position controls move the element left/right, up/down or forward/back. Size keeps its proportions. Tilt turns flat cutouts around their upright axis; opposite tilt directions can face left and right decorations toward the puzzle.

Pom is approximately dog-sized as a visual reference. Individual daisies should read as flowers beside him; a daisy patch is a group of flowers.

## Camera and backdrop

Drag empty scene space to pan, scroll or pinch to zoom, and use the view control to compare angles. Panning is bounded around the stage. Center on Pom resumes the game’s camera follow; panning or dragging scenery pauses it.

Backdrop distance accepts 0.5–80. Automatic distance restores spacing based on puzzle size. Side views may require more distance to keep the wall clear of the puzzle. Scenery placed behind a nearby wall may become hidden.

Camera pan, zoom and temporary follow state are not saved as part of an environment configuration.

## Cutout materials and supports

Shared cutout material provides padding width, padding color, depth and edge color for planted elements. Padding extends around the image silhouette. Depth gives the cutout a cardboard edge.

Material & support overrides these properties for the selected copy. Reset element material restores its inherited defaults. Clouds and fog default to zero padding and depth, but each copy can override them.

Cutout support adds a cardboard brace behind an element, using its padding color. Floating elements can produce long braces. Supports have no effect on puzzle movement.

Padding and edge geometry stop at ground level independently of the painted front. Normal scene occlusion still applies to the image.

## Shadows

Environment shadow strength controls scenery shadows independently from puzzle shadows. Zero hides projected scenery shadows; painted shading in the artwork remains visible.

Ground shadow blur softens both puzzle and scenery shadows falling on the ground. It does not change puzzle-face shading. Scenery projects onto the ground and backdrop wall; overlapping shadows may darken. Supports do not currently add projected silhouettes.

## Save and compare

Enter a name and choose Save new configuration to retain a snapshot. Repeated saves create separate alternatives. Choose a saved configuration and Load configuration to bring it into the working preview. Deleting a saved configuration keeps the current preview.

Export configuration downloads a JSON file that you can share or keep as a backup. Import configuration loads a compatible file into the preview; save a new configuration afterward to keep it in the library. Files reference installed artwork and do not contain the images themselves.

Drafts and saved configurations are local to this browser. Export important work before changing devices or clearing browser data.

## Apply to gameplay

Normal gameplay uses the approved Daisy Meadow scene outside Japan. Japan levels retain Japan Spring. Studio keeps its own working draft.

Apply to non-Japan levels saves an explicit local gameplay override. Further edits stay in Studio until you apply again. Use game defaults restores the approved gameplay scene and keeps Studio drafts and saved configurations.

Reset preview resets the working preview. It does not delete your named configurations.
